🌍 Local Tourism Explorer

Local Tourism Explorer is a responsive web application that helps users discover and explore popular local tourist destinations, attractions, culture, food, and travel experiences.

The project features an attractive homepage, destination cards, images, travel information, and interactive destination details. It is designed to provide a simple and engaging way for users to explore places such as Chennai, Ooty, Mahabalipuram, and Madurai.
